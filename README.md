# Affiliate Agent OS V0.1

Dashboard mobile untuk mengelola produk, draft skrip template, antrean jadwal, catatan performa dan backup.

## Deploy GitHub Pages
Upload semua file ke root repository pada branch `main`. Buka Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Batasan
Belum terhubung ke API AI, Shopee, database cloud atau auto-publish. Data disimpan di localStorage browser. Integrasi otomatis berikutnya membutuhkan backend aman dan API resmi. Jangan menaruh secret key di JavaScript publik.
